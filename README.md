# INT6136P · 专题研讨室

独立的普通话课程网站，以设计思维支持约 20 分钟的小组专题报告。保留 INT6066 的协作、自动保存、个人贡献、版本记录和教师反馈机制，调整为本课程的选题、资料研究、深入讨论和反思任务。所有平台提示为中文；用户给定的组名和课程编号保持原样。

## 课程任务

学生自主选择与本科目内容相关的主题，结合课堂知识与概念，全面研究近期文章、期刊论文、案例及其他相关资料，进行深入讨论和反思，并向全班进行约 20 分钟的小组专题报告。平台组织和留存学习过程，不代替课程原有评分要求。

## 设计思维与网站流程

首页展示中文的设计思维循环图：共情理解 → 定义问题 → 构思方案 → 形成原型 → 测试检验 → 实施迭代。它与以下九个工作步骤对应：

1. **个人阅读与选题**：从相关人群、情境和课程现象出发，每位成员记录个人观察或查阅的资料。保留资料标题、情境、阅读发现、来源类别、真实引用、年份和可选链接或附件。
2. **小组交流**：阅读成员的资料，发表评论，记录初步聚焦。
3. **依据与待查问题**：明确研究领域与课程联系；区分已查到的资料、解释和仍需查证的问题。
4. **研究小结**：审阅共情与研究依据，确认进入定义阶段。
5. **整理主题与观点**：归纳观点、分歧或模式，并关联研究资料。
6. **确定报告主题**：选择有依据的主题，说明希望促进的理解或学习。
7. **规划 20 分钟报告**：界定研究问题、范围、理由和课程概念，设计有标题、时长和内容的报告环节。时间目标是约 20 分钟，不强制精确到 20 分钟。负责人和分工可选。
8. **讨论反思与提交**：写出资料综合、主要论点、批判性反思和面向全班的讨论问题，再保存小组版本。
9. **已保存的报告方案**：回看版本、研究资料、报告提纲、成员贡献和教师反馈，导出记录或打印，返回草稿继续迭代。

报告提纲是可供预演的原型；讨论问题、批判性反思和教师反馈支持检验。学生仍需按课程要求实际进行课堂报告，平台不会把保存方案等同于已完成课堂呈现。

## 独立展示作品提交

学生可通过顶部导航或小组工作区的“展示作品提交”进入独立作品区（/works）。它不受九步流程的前置条件限制，和“提交报告方案”分别保存。

- 作品标题、作品类型必填；至少提供一个文件或完整 HTTP(S) 链接。作品说明、链接名称可选。
- 类型包括展示 PPT、报告原型、分析的工具／网站和其他作品。报告原型可为 PPT 初稿、提纲或讨论活动设计；分析的网站属于研究对象，类型不表示小组开发了该工具。
- 支持 PPT、PPTX、PDF、Word、JPG／PNG／WebP；每个文件最大 20 MB，每次最多 5 个文件和 5 个链接。大于上限的作品可用可访问的共享链接提交。
- 文件分块上传并保存在现有 PostgreSQL 数据库，无需新增存储环境变量。页面显示进度，失败后可在同一页面重试；正式提交完成后才对其他组员及教师可见。
- 作品提交保留独立版本，不覆盖旧作品。方案版本和作品版本分别编号。
- Nicole 打开一个小组时，靠上的“展示作品与原型”区显示作品类型、标题、提交者、时间、版本、文件下载、图片预览及作品链接。教师小组卡片显示提交的作品数量。
- 文件仅供已登录的本组成员与教师访问；读取分块后在浏览器合并下载。服务器检查文件数量、大小、完整性、格式及小组权限。

## 必填与选填

页面明确标记“必填”“选填”和“添加后需填完整”。必填项不足时，继续按钮不会启用；侧边栏、直接网址和服务端也校验前置步骤。

- 每个学生至少先保存一条自己的记录，才可进入后续协作步骤。无需等待全部成员加入，已保存的小组版本始终可查看。
- 小组研究阶段至少选择两条不同的真实研究资料，其中至少一条为研究文章或期刊论文。个人经验及待验证想法可以用于共情，但不会算作已发表研究依据。
- 研究资料需保留真实引用。文章和期刊需填写真实发表年份；无日期的案例或其他资料可在引用中注明“无日期”。资料链接及图片/PDF 附件为选填，附件最大 2 MB。
- 解释、反例、评论、负责人、分工、向教师提问、后续计划和个人反思为选填。
- 完全空白的新增行不阻止继续；开始填写的行需补完整或删除。
- 最终方案需要至少两个完整的报告环节，以及资料综合、批判性反思和讨论问题。

上述是平台引导条件，不表示课程另有新增的评分条款。近期资料和多元来源仍需小组根据主题主动选择并评价。

## 项目与部署

Next.js App Router、React、TypeScript、Prisma 7、标准 PostgreSQL。字体为本地 Noto Sans SC 可变字体，含许可证；浏览器无需连接外部字体服务。Node.js 主版本固定为 22.x。

这是独立项目。**新建 Vercel 项目及独立数据库，不要覆盖 INT6066 项目或复用其数据库。** INT6136P 的迁移、课程标识、登录令牌与浏览器备份均独立；误连其他课程数据库会报错。

详细部署步骤见 [VERCEL部署指南.md](./VERCEL部署指南.md)。需要以下三个服务端环境变量，勾选对应的 Production、Preview 环境后重新部署：

- DATABASE_URL：Prisma Postgres 的标准 PostgreSQL 连接地址。
- SESSION_SECRET：独立、稳定的至少 32 字符随机值。
- TEACHER_PASSWORD：Nicole 的教师入口密码。

构建命令 npm run vercel-build 会先校验环境变量、应用数据库迁移，再构建页面。部署配置已包含在 vercel.json 中。postinstall 负责生成 Prisma Client。

## 本地运行与检查

安装依赖后运行 npm run dev:local，默认打开 http://127.0.0.1:3010。本地持久 PostgreSQL 保存于 .local-data，与 INT6066 的预览和云端数据库分开。无需云端连接密钥；本地会生成临时 SESSION_SECRET。

常用检查：npm test、npm run typecheck、npm run build、npm run test:integration、npm run test:migration。集成测试使用独立临时数据库与端口；不会写入课程记录。检查结果见 VERIFICATION.md。

交付压缩包不包含 node_modules、构建缓存、本地学生数据、真实数据库连接或会话密钥。不要把 .env.local 提交到 GitHub。
